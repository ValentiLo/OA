## Ответы на контрольные вопросы

### 1. Что такое среда программирования? Какие среды вы знаете?

**Среда программирования (IDE)** — это программа для написания, запуска и отладки кода. Включает редактор кода, интерпретатор, терминал и отладчик.

**Примеры:** IDLE, PyCharm, VS Code, Thonny, онлайн-компиляторы (Replit, OnlineGDB).

### 2. Как запустить программу на Python?

**В IDLE:** File → New File → написать код → Run → Run Module (или **F5**).

**В VS Code:** открыть файл `.py` → нажать **▶ Run** или **Ctrl+F5**.

**В онлайн-компиляторе:** написать код → нажать **Run**.

### 3. Что делает функция `print()`?

Выводит данные на экран. Может принимать несколько аргументов, строки, числа, результаты выражений.

### 4. Как вывести несколько значений через запятую?

```python
print("a", "b", "c")
```

Вывод: `a b c` (через пробел).

**С запятой:**
```python
print("a", "b", "c", sep=", ")
```

Вывод: `a, b, c`.

### 5. Что делают параметры `sep` и `end` у `print()`?

- **`sep`** — разделитель между аргументами (по умолчанию — пробел).
- **`end`** — что выводить в конце (по умолчанию — `\n`, перевод строки).

**Пример:**
```python
print("a", "b", sep="-", end="!")
```

Вывод: `a-b!`

### 6. Что делает функция `input()`?

Читает строку с клавиатуры. **Всегда возвращает строку** (`str`).

**Пример:**
```python
name = input("Введите имя: ")
```

### 7. Какой тип данных возвращает `input()`?

**Всегда `str`** (строку). Даже если пользователь ввёл число — это будет строка.

**Проверка:**
```python
x = input("Введите число: ")
print(type(x))   # <class 'str'>
```

### 8. Как преобразовать строку в число?

- **`int()`** — в целое: `int("42")` → `42`.
- **`float()`** — в вещественное: `float("3.14")` → `3.14`.

**Пример:**
```python
age = int(input("Введите возраст: "))
```

### 9. Что произойдёт, если сложить строку и число без преобразования?

**Ошибка `TypeError`:**
```
TypeError: can only concatenate str (not "int") to str
```

**Пример:**
```python
age = input("Возраст: ")   # строка "18"
print(age + 1)              # ← ошибка
```

**Правильно:**
```python
age = int(input("Возраст: "))
print(age + 1)              # 19
```

### 10. Как вывести число с двумя знаками после запятой?

**Через f-строку:**
```python
x = 3.14159
print(f"{x:.2f}")   # 3.14
```

**Через `format`:**
```python
print("{:.2f}".format(x))   # 3.14
```

## 2. Что такое логическое выражение

**Логическое выражение** — выражение, которое принимает одно из двух значений:

- **`True`** — истина.
- **`False`** — ложь.

**Тип данных:** `bool`.

**Пример:**

```python
x = 5
print(x > 3)        # True
print(x == 10)      # False
print(x != 3)       # True
```

Логические выражения используются в:

- **Условиях `if`** — что делать, если истина.
- **Циклах `while`** — продолжать, пока истина.
- **Фильтрации** — отобрать подходящие элементы.
- **Флагах** — хранить состояние.

## 3. Операторы сравнения

### 3.1. Основные операторы

| Оператор | Что означает | Пример | Результат |
|:--------:|--------------|--------|:---------:|
| `==` | Равно | `5 == 5` | `True` |
| `!=` | Не равно | `5 != 3` | `True` |
| `>` | Больше | `5 > 3` | `True` |
| `<` | Меньше | `5 < 3` | `False` |
| `>=` | Больше или равно | `5 >= 5` | `True` |
| `<=` | Меньше или равно | `5 <= 3` | `False` |

⚠️ **Не путайте:**
- `=` — **присваивание** (`x = 5`).
- `==` — **сравнение** (`x == 5`).

```python
x = 5      # присваивание
x == 5     # сравнение → True
```

### 3.2. Сравнение чисел

```python
print(10 > 5)       # True
print(10 < 5)       # False
print(10 == 10)     # True
print(10 != 10)     # False
print(-5 < 0)       # True
print(3.14 > 3)     # True
```

### 3.3. Сравнение строк

Строки сравниваются **лексикографически** — по символам (их ASCII-кодам).

```python
print("apple" == "apple")    # True
print("apple" < "banana")    # True (a < b)
print("Apple" < "apple")     # True (A < a)
print("abc" < "abd")         # True (c < d)
print("abc" < "abcd")        # True (короче — меньше)
```

⚠️ **Регистр важен:** `"Apple"` ≠ `"apple"`.

### 3.4. Цепочки сравнений

Python поддерживает **цепочки**:

```python
x = 5
print(0 < x < 10)      # True (то же, что 0 < x and x < 10)
print(1 < x < 3)       # False
print(0 <= x <= 5)     # True
```

**Это удобно** — не нужно писать `and`.

⚠️ **Ловушка с `!=`:**

```python
x = 5
x != 3 != 5
# = (5 != 3) and (3 != 5)
# = True and True
# = True
```

**Цепочка `!=` проверяет соседние элементы**, а не «x не равен ни одному».

### 3.5. Сравнение с `None`

```python
x = None
print(x is None)       # True (правильно)
print(x == None)       # True (работает, но не рекомендуется)
```

⚠️ **Рекомендуется `is`** для `None`, `True`, `False`.

## 4. Логические операторы

### 4.1. `and` — логическое И

**Истинно, только если оба операнда истинны.**

| A | B | A and B |
|:-:|:-:|:-------:|
| True | True | **True** |
| True | False | False |
| False | True | False |
| False | False | False |

**Пример:**

```python
age = 20
has_passport = True

if age >= 18 and has_passport:
    print("Можно войти")
```

**Идея:** «и то, и другое».

### 4.2. `or` — логическое ИЛИ

**Истинно, если хотя бы один операнд истинен.**

| A | B | A or B |
|:-:|:-:|:------:|
| True | True | **True** |
| True | False | **True** |
| False | True | **True** |
| False | False | False |

**Пример:**

```python
is_weekend = True
is_holiday = False

if is_weekend or is_holiday:
    print("Можно отдыхать")
```

**Идея:** «или то, или другое».

### 4.3. `not` — логическое НЕ

**Инвертирует значение.**

| A | not A |
|:-:|:-----:|
| True | **False** |
| False | **True** |

**Пример:**

```python
is_raining = False

if not is_raining:
    print("Можно идти гулять")
```

**Идея:** «наоборот».

```
True  and True  → True
True  and False → False
False and True  → False
False and False → False
```

### 5.2. `or`

```
True  or True  → True
True  or False → True
False or True  → True
False or False → False
```

### 5.3. `not`

```
not True  → False
not False → True
```

## 6. Приоритет операторов

От высшего к низшему:

| Приоритет | Операторы |
|:---------:|-----------|
| 1 | `**` |
| 2 | `+x`, `-x` (унарные) |
| 3 | `*`, `/`, `//`, `%` |
| 4 | `+`, `-` |
| 5 | `==`, `!=`, `<`, `>`, `<=`, `>=` |
| 6 | `not` |
| 7 | `and` |
| 8 | `or` |

**Мнемоника:** **NOT → AND → OR**.

⚠️ **Скобки меняют приоритет.** Используйте их для ясности.

**Пример:**

```python
x = 5
print(not x > 3)          # not (x > 3) = not True = False
print(not (x > 3))        # то же
print(x > 3 and x < 10)   # True and True = True
print(x > 3 or x < 0)     # True or False = True
```

## 7. Короткое замыкание (short-circuit)

Python **не вычисляет** второй операнд, если результат уже ясен.

### 7.1. `and`

Если первый — `False`, второй **не проверяется**.

```python
def check():
    print("check вызвана")
    return True

print(False and check())   # False, "check вызвана" НЕ печатается
print(True and check())    # True, "check вызвана" печатается
```

### 7.2. `or`

Если первый — `True`, второй **не проверяется**.

```python
print(True or check())     # True, "check вызвана" НЕ печатается
print(False or check())    # True, "check вызвана" печатается
```

### 7.3. Зачем это нужно

**Защита от ошибок:**

```python
x = 0
if x != 0 and 10 / x > 1:    # деление на ноль не произойдёт
    print("OK")
```

Если бы `and` не был коротким, `10 / x` вызвало бы ошибку.

**Значение по умолчанию:**

```python
name = user_input or "Гость"
```

Если `user_input` пустой (`False`), берётся `"Гость"`.

## 8. Возврат значений

В Python `and` и `or` возвращают **не `True`/`False`**, а **один из операндов**.

### 8.1. `and`

- Возвращает **первый ложный** операнд.
- Если все истинны — **последний**.

```python
print(5 and 10)        # 10
print(0 and 10)        # 0
print("" and "abc")    # ""
print("abc" and "xyz") # "xyz"
```

### 8.2. `or`

- Возвращает **первый истинный** операнд.
- Если все ложны — **последний**.

```python
print(5 or 10)         # 5
print(0 or 10)         # 10
print("" or "abc")     # "abc"
print(None or 0)       # 0
```

### 8.3. Идиомы Python

**Значение по умолчанию:**

```python
name = user_input or "Аноним"
```

**Проверка и действие:**

```python
items = []
items and print("Есть элементы")   # не выполнится
```

## 9. Что считается истиной и ложью

### 9.1. Ложные значения (falsy)

| Значение | Что это |
|----------|---------|
| `False` | Ложь |
| `None` | Ничего |
| `0` | Ноль |
| `0.0` | Ноль |
| `""` | Пустая строка |
| `[]` | Пустой список |
| `{}` | Пустой словарь |
| `set()` | Пустое множество |
| `()` | Пустой кортеж |

### 9.2. Истинные значения (truthy)

**Всё остальное** — истинно.

```python
if []:
    print("Никогда")     # пустой список — False

if [1, 2]:
    print("Сработает")   # непустой — True

if "hello":
    print("Сработает")   # непустая строка — True
```

**Практический пример:**

```python
items = []
if not items:
    print("Список пуст")
```

## 10. Побитовые операторы vs логические

⚠️ **Не путайте:**

| Логические | Побитовые |
|:----------:|:---------:|
| `and` | `&` |
| `or` | `\|` |
| `not` | `~` |

**Логические** — для условий.

**Побитовые** — для работы с битами:

```python
a = 5   # 0101
b = 3   # 0011
print(a & b)   # 0001 = 1
print(a | b)   # 0111 = 7
print(a ^ b)   # 0110 = 6
```

⚠️ **`&` и `|` имеют более высокий приоритет**, чем `and`/`or`. Не используйте их в условиях, если не уверены.

## 12. Типичные ошибки

| Ошибка | Что не так | Правильно |
|--------|-----------|-----------|
| `if x = 5:` | Присваивание вместо сравнения | `if x == 5:` |
| `if x == 5 or 10:` | Проверка `x == 5` или `10` (всегда True) | `if x == 5 or x == 10:` |
| `if 0 < x < 10` | ОК | ОК |
| `if x != 3 != 5:` | Ловушка цепочки | `if x != 3 and x != 5:` |
| `if x == "5":` при `x = 5` | Разные типы | Преобразовать |
| Забыли скобки в сложных условиях | Приоритет | Использовать `()` |
| `and` вместо `or` | Логика неверна | Подумать, что нужно |

**Пример ошибки:**

```python
x = 5
if x == 5 or 10:
    print("Сработает всегда!")   # ❌ 10 — истина
```

**Правильно:**

```python
if x == 5 or x == 10:
    print("x равен 5 или 10")
```

**Или через `in`:**

```python
if x in (5, 10):
    print("x равен 5 или 10")
```
Отличный вопрос — тут важно разделить **два уровня**: что такое сами `True`/`False` и что Python считает истиной/ложью в условии.

## 1. Что такое `True` и `False` в Python

`True` и `False` — это **значения встроенного типа `bool`** (булев тип).

```python
type(True)    # <class 'bool'>
type(False)   # <class 'bool'>
```

Важные факты:
- Это **отдельный тип**, а не числа (хотя исторически `bool` — подкласс `int`).
- Они **единственные** представители типа `bool` — других значений нет.
- Пишутся **с большой буквы**: `True`, `False`. Не `true`/`false` (это ошибка!).
- Это **ключевые слова**, их нельзя переопределить как имя переменной.

```python
True = 5   # SyntaxError: cannot assign to True
```

Проверка:
```python
x = 5 > 3
print(x)          # True
print(type(x))    # <class 'bool'>
```

## 2. Что «принимает» `if` — не только bool

Вот ключевой момент. **`if` принимает любой объект**, а не только `True`/`False`.

```python
if True:      # сработает
if False:     # не сработает
if 5:         # сработает (5 — truthy)
if 0:         # не сработает (0 — falsy)
if "abc":     # сработает
if []:        # не сработает
if None:      # не сработает
```

Python внутри делает так:
```python
if X:
```
превращается в:
```python
if bool(X):
```
То есть **любое значение приводится к `True` или `False`** через `bool()`.

## 3. Что `bool()` возвращает для разных типов

```python
bool(True)     # True
bool(False)    # False

bool(1)        # True
bool(0)        # False

bool("hello")  # True
bool("")       # False

bool([1, 2])   # True
bool([])       # False

bool(None)     # False
```

Полный список Falsy-значений (всё остальное — True):

| Falsy | Тип |
|---|---|
| `False` | bool |
| `None` | NoneType |
| `0`, `0.0`, `0j` | числа |
| `""` | строка |
| `[]` | список |
| `()` | кортеж |
| `{}` | словарь |
| `set()` | множество |

## 4. Откуда берутся `True`/`False` — операторы сравнения и логики

### Операторы сравнения → возвращают bool

```python
5 > 3       # True
5 < 3       # False
5 == 5      # True
5 != 5      # False
5 >= 5      # True
5 <= 4      # False
"a" == "a"  # True
```

### Логические операторы → возвращают один из операндов (не всегда bool!)

Это важный нюанс:

```python
True and False    # False
True or False     # True
not True          # False
```

Но:
```python
5 and 10      # 10   (не True!)
0 or "hi"     # "hi" (не True!)
"" or []      # []
```

`and`/`or` возвращают **не `True`/`False`, а один из своих операндов**. Просто в `if` это значение потом приводится к bool.

Пример:
```python
name = "" or "Гость"
print(name)   # "Гость"  — вернулась строка, не True
```

## 5. Как `if` работает с этим на практике

```python
x = 5 and 10     # x = 10
if x:            # bool(10) → True
    print("да")  # сработает
```

```python
x = 0 or ""      # x = ""
if x:            # bool("") → False
    print("да")  # не сработает
```

## 6. Частые ошибки

**Ошибка 1 — писать `true`/`false`:**
```python
if true:   # NameError: name 'true' is not defined
```

**Ошибка 2 — сравнивать с `True`/`False` явно:**
```python
# Плохо
if x == True:
    ...

# Хорошо
if x:
    ...
```
Потому что `x` может быть `5`, `"abc"` и т.д. — всё truthy.

**Ошибка 3 — путать `=` и `==`:**
```python
if x = 5:    # SyntaxError
if x == 5:   # правильно
```

**Ошибка 4 — думать, что `and`/`or` возвращают bool:**
```python
result = 5 or 10
print(result)        # 5, а не True
print(type(result))  # <class 'int'>
```

## 7. Мини-шпаргалка

```python
# Что такое True/False

# Операторы сравнения → bool

# Приведение
bool(5)      # True
bool(0)      # False
bool("")     # False
bool("0")    # True
```

## Запомнить

> **`True` и `False` — это два значения типа `bool`.**
> **`if` принимает любое значение**, но внутри приводит его к `bool`: truthy → как `True`, falsy → как `False`.
> **Falsy:** `False`, `None`, `0`, `0.0`, `""`, `[]`, `()`, `{}`, `set()`.
> **Всё остальное — truthy.**

## 13. Итоги

- **Логическое выражение** — `True` или `False`.
- **Операторы сравнения:** `==`, `!=`, `>`, `<`, `>=`, `<=`.
- **Логические операторы:** `and`, `or`, `not`.
- **Приоритет:** `not` → `and` → `or`.
- **Короткое замыкание** — экономит вычисления.
- **`and`/`or`** возвращают один из операндов, а не `True`/`False`.
- **Falsy:** `0`, `""`, `[]`, `None`, `False`.
- **Цепочки сравнений:** `0 < x < 10`.
- **Осторожно** с `!=` в цепочках.

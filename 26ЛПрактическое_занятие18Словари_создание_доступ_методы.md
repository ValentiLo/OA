## 2. Краткая теория

### 2.1. Создание словаря

```python
student = {"name": "Иван", "age": 20, "group": 214}
student = dict(name="Иван", age=20)
student = dict([("name", "Иван"), ("age", 20)])
empty = {}
```

### 2.2. Доступ по ключу

| Способ | Что делает |
|--------|-----------|
| `d[key]` | Значение или `KeyError` |
| `d.get(key)` | Значение или `None` |
| `d.get(key, default)` | Значение или `default` |
| `key in d` | Проверка наличия |

### 2.3. Методы

| Метод | Что делает |
|-------|-----------|
| `keys()` | Все ключи |
| `values()` | Все значения |
| `items()` | Пары (ключ, значение) |
| `get(k, d)` | Значение или default |
| `update(d)` | Обновить словарь |
| `pop(k)` | Удалить и вернуть |
| `popitem()` | Удалить последнюю пару |
| `clear()` | Очистить |
| `copy()` | Копия |
| `setdefault(k, d)` | Получить или создать |

### 2.4. Изменение

```python
d["key"] = value      # добавить или изменить
del d["key"]          # удалить
d.pop("key")          # удалить и вернуть
```

### 🟠 Уровень 3. Работа со словарями

#### Задание 11. Подсчёт частоты слов

**Условие:** посчитать частоту слов в тексте.

**Решение:**

```python
text = "кот пёс кот кот пёс"
words = text.split()
freq = {}

for word in words:
    freq[word] = freq.get(word, 0) + 1

print(freq)   # {'кот': 3, 'пёс': 2}
```

---

#### Задание 12. Самое частое слово

**Условие:** найти самое частое слово в тексте.

**Решение:**

```python
text = "кот пёс кот кот пёс мышь"
words = text.split()

freq = {}
for word in words:
    freq[word] = freq.get(word, 0) + 1

most_common = max(freq, key=freq.get)
print(f"Самое частое: {most_common} ({freq[most_common]} раз)")
```

**Вывод:**
```
Самое частое: кот (3 раз)
```

#### Задание 16. Сортировка словаря по значениям

**Условие:** дан словарь частот. Отсортировать по убыванию.

**Решение:**


#### Задание 18. Группировка по ключу

**Условие:** дан список студентов с группами. Сгруппировать по группам.

**Решение:**

```python
students = [
    {"name": "Иван", "group": 214},
    {"name": "Анна", "group": 215},
    {"name": "Пётр", "group": 214},
    {"name": "Мария", "group": 215}
]

groups = {}
for s in students:
    groups.setdefault(s["group"], []).append(s["name"])

for group, names in groups.items():
    print(f"Группа {group}: {', '.join(names)}")
```

**Вывод:**
```

```

#### Задание 19. Слияние словарей

**Условие:** объединить два словаря. При совпадении ключей — сложить значения.

**Решение:**

```python
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}

result = d1.copy()
for key, value in d2.items():
    result[key] = result.get(key, 0) + value

print(result)   # {'a': 1, 'b': 5, 'c': 4}
```

#### Задание 20. Мини-система: справочник

**Условие:** реализовать мини-справочник:

- `1` — добавить запись
- `2` — найти по имени
- `3` — вывести все
- `0` — выход

**Решение:**

```python
contacts = {}

while True:
    print("\n1. Добавить")
    print("2. Найти")
    print("3. Все")
    print("0. Выход")

    choice = input("Выбор: ")

    if choice == "0":
        print("До свидания")
        break
    elif choice == "1":
        name = input("Имя: ")
        phone = input("Телефон: ")
        contacts[name] = phone
        print("Добавлено")
    elif choice == "2":
        name = input("Имя: ")
        print(contacts.get(name, "Не найден"))
    elif choice == "3":
        for name, phone in contacts.items():
            print(f"{name}: {phone}")
    else:
        print("Неверный выбор")
```

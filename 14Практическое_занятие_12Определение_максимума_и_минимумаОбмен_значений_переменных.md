# Практическое занятие 12. Определение максимума и минимума. Обмен значений переменных

## Теория

### Что такое максимум и минимум

В программировании задачи на поиск максимума и минимума встречаются постоянно. Нужно найти самого старшего сотрудника, самый дорогой товар, наименьшую зарплату, максимальную оценку и так далее. Задача сводится к перебору значений и запоминанию лучшего.

### Три способа поиска максимума

#### Способ 1. Через встроенную функцию `max()` (самый простой)

Python умеет находить максимум из готового набора значений одной командой:

```python
a = int(input("Первое число: "))
b = int(input("Второе число: "))
c = int(input("Третье число: "))

print(f"Максимум: {max(a, b, c)}")
```

**Плюсы:** одна строка, минимум ошибок.
**Минусы:** работает только если все значения уже есть в памяти. Если числа вводятся в цикле, функция `max()` не поможет.

#### Способ 2. Через условный оператор (для двух-трёх чисел)

Если значений немного, можно обойтись `if-else`:

```python
a = int(input("Первое число: "))
b = int(input("Второе число: "))

if a > b:
    maximum = a
else:
    maximum = b

print(f"Максимум: {maximum}")
```

Или короче, через тернарный оператор:

```python
maximum = a if a > b else b
```

**Плюсы:** наглядно.
**Минусы:** для десяти чисел придётся писать десять условий.

#### Способ 3. Через цикл (универсальный)

Когда чисел много или они вводятся в цикле, используют «эталон» — начальное значение, с которым сравнивают все остальные.

**Алгоритм:**
1. Взять первое значение за текущий максимум.
2. Для каждого следующего значения: если оно больше текущего максимума — обновить максимум.
3. В конце — в максимуме лежит самое большое значение.

```python
n = int(input("Сколько чисел? "))
maximum = int(input("Число 1: "))

for i in range(2, n + 1):
    x = int(input(f"Число {i}: "))
    if x > maximum:
        maximum = x

print(f"Максимум: {maximum}")
```

**Плюсы:** работает для любого количества чисел.
**Минусы:** нужно аккуратно выбрать начальное значение.

### Ловушка с начальным значением

Одна из самых частых ошибок — поставить `maximum = 0`. Если все числа отрицательные, программа выдаст `0`, которого среди чисел не было.

```python
# НЕПРАВИЛЬНО
maximum = 0
for x in [-5, -3, -8]:
    if x > maximum:
        maximum = x
print(maximum)  # 0, хотя максимум = -3
```

Правильно — брать первое число последовательности:

```python
# ПРАВИЛЬНО
numbers = [-5, -3, -8]
maximum = numbers[0]
for x in numbers:
    if x > maximum:
        maximum = x
print(maximum)  # -3
```

### Поиск минимума

Аналогично максимуму, только знак сравнения меняется на `<`:

```python
numbers = [5, 3, 8, 1]
minimum = numbers[0]
for x in numbers:
    if x < minimum:
        minimum = x
print(minimum)  # 1
```

### Обмен значений переменных

Задача: поменять местами значения двух переменных. Например, было `a = 5`, `b = 3`, стало `a = 3`, `b = 5`.

#### Способ 1. Через временную переменную (классический)

```python
a = 5
b = 3

temp = a
a = b
b = temp

print(a, b)  # 3 5
```

**Как это работает:**
- `temp = a` — запомнили старое значение `a` (5).
- `a = b` — в `a` положили значение `b` (3).
- `b = temp` — в `b` положили старое значение `a` (5).

Без `temp` не обойтись: если сразу написать `a = b`, то значение `a` потеряется.

#### Способ 2. Через кортежи (питонический)

В Python есть элегантный способ обмена в одну строку:

```python
a = 5
b = 3

a, b = b, a

print(a, b)  # 3 5
```

**Как это работает:** Python сначала вычисляет правую часть (`b, a`) — получается кортеж `(3, 5)`. Затем распаковывает его в переменные слева. Всё происходит атомарно, без временной переменной.

#### Способ 3. Через арифметику (для чисел)

Можно обойтись без временной переменной, используя сложение и вычитание:

```python
a = 5
b = 3

a = a + b   # a = 8
b = a - b   # b = 5
a = a - b   # a = 3

print(a, b)  # 3 5
```

Или через умножение и деление:

```python
a = 5
b = 3

a = a * b   # a = 15
b = a // b  # b = 5
a = a // b  # a = 3
```

**Минусы:** работает только для чисел. При делении возможна потеря точности. В реальном коде так делать не стоит — это учебный трюк.

## Одна задача, решённая всеми способами

**Задача:** Пользователь вводит три числа. Найти максимум и минимум, поменять их местами.

### Способ 1. Через встроенные функции

```python
a = float(input("a: "))
b = float(input("b: "))
c = float(input("c: "))

maximum = max(a, b, c)
minimum = min(a, b, c)

print(f"Максимум: {maximum}")
print(f"Минимум: {minimum}")

# Обмен через кортеж
maximum, minimum = minimum, maximum
print(f"После обмена: максимум = {maximum}, минимум = {minimum}")
```

### Способ 2. Через условные операторы

```python
a = float(input("a: "))
b = float(input("b: "))
c = float(input("c: "))

# Поиск максимума
if a >= b and a >= c:
    maximum = a
elif b >= a and b >= c:
    maximum = b
else:
    maximum = c

# Поиск минимума
if a <= b and a <= c:
    minimum = a
elif b <= a and b <= c:
    minimum = b
else:
    minimum = c

print(f"Максимум: {maximum}")
print(f"Минимум: {minimum}")

# Обмен через временную переменную
temp = maximum
maximum = minimum
minimum = temp
print(f"После обмена: максимум = {maximum}, минимум = {minimum}")
```

### Способ 3. Через цикл и список

```python
numbers = []
for i in range(1, 4):
    x = float(input(f"Число {i}: "))
    numbers.append(x)

maximum = numbers[0]
minimum = numbers[0]
for x in numbers:
    if x > maximum:
        maximum = x
    if x < minimum:
        minimum = x

print(f"Максимум: {maximum}")
print(f"Минимум: {minimum}")

# Обмен через арифметику
maximum = maximum + minimum
minimum = maximum - minimum
maximum = maximum - minimum
print(f"После обмена: максимум = {maximum}, минимум = {minimum}")
```

### Сравнение способов

| Способ | Плюсы | Минусы |
|--------|-------|--------|
| `max()` / `min()` | Одна строка, читаемо | Только для готовых значений |
| `if-elif-else` | Наглядно для 2–3 чисел | Много кода для большого количества |
| Цикл | Универсально | Больше строк кода |
| Временная переменная | Работает всегда | Нужна лишняя переменная |
| Кортеж | Кратко, питонично | Непривычно для новичков |
| Арифметика | Без лишней переменной | Только для чисел, риск переполнения |

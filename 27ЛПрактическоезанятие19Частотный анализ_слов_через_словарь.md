## 2. Краткая теория

### 2.1. Идея частотного анализа

**Частотный анализ** — подсчёт, сколько раз встречается каждый элемент.

**Схема:**

1. Разбить текст на слова.
2. Для каждого слова увеличить счётчик в словаре.
3. Получить словарь `{слово: количество}`.

### 2.2. Основной приём

```python
freq = {}
for word in words:
    freq[word] = freq.get(word, 0) + 1
```

**`freq.get(word, 0)`** — если слова нет, вернёт `0`, иначе — текущее значение.

### 2.3. Альтернативы

| Способ | Как |
|--------|-----|
| `get()` | `freq[w] = freq.get(w, 0) + 1` |
| `setdefault()` | `freq.setdefault(w, 0); freq[w] += 1` |
| `Counter` | `from collections import Counter` |
| `defaultdict` | `from collections import defaultdict` |

### 2.4. Сортировка по частоте

```python
sorted_items = sorted(freq.items(), key=lambda x: x[1], reverse=True)
```

## 3. Задания для выполнения

### 🟢 Уровень 1. Базовые задачи

#### Задание 1. Частота слов в строке

**Условие:** посчитать частоту слов в строке `"кот пёс кот кот пёс"`.

**Решение:**

```python
text = "кот пёс кот кот пёс"
words = text.split()

freq = {}
for word in words:
    freq[word] = freq.get(word, 0) + 1

print(freq)   # {'кот': 3, 'пёс': 2}
```

#### Задание 3. Самое частое слово

**Условие:** найти самое частое слово в тексте.

**Решение:**

```python
text = "кот пёс кот кот пёс мышь"
words = text.split()

freq = {}
for w in words:
    freq[w] = freq.get(w, 0) + 1

most_common = max(freq, key=freq.get)
print(f"Самое частое: {most_common} ({freq[most_common]} раз)")
```

**Вывод:**
```
Самое частое: кот (3 раз)
```

#### Задание 20. Полный анализ текста

**Условие:** реализовать полный анализ текста:

- количество слов,
- количество уникальных слов,
- топ-3 слова,
- самое длинное слово,
- средняя длина слова.

**Решение:**

```python
def analyze(text):
    words = text.lower().split()

    freq = {}
    for w in words:
        freq[w] = freq.get(w, 0) + 1

    top3 = sorted(freq.items(), key=lambda x: -x[1])[:3]
    longest = max(words, key=len)
    avg_len = sum(len(w) for w in words) / len(words)

    return {
        "total": len(words),
        "unique": len(freq),
        "top3": top3,
        "longest": longest,
        "avg_len": avg_len
    }

text = "Python это очень круто Python это лучший язык"
result = analyze(text)

print(f"Всего слов: {result['total']}")
print(f"Уникальных: {result['unique']}")
print(f"Топ-3: {result['top3']}")
print(f"Самое длинное: {result['longest']}")
print(f"Средняя длина: {result['avg_len']:.2f}")
```

**Вывод:**
```
Всего слов: 8
Уникальных: 6
Топ-3: [('python', 2), ('это', 2), ('очень', 1)]
Самое длинное: лучший
Средняя длина: 4.50
```

## 2. Что такое словарь

**Словарь (`dict`)** — это **неупорядоченная** коллекция пар **«ключ → значение»**.

**Ключевые свойства:**
- **Ключи уникальны** — не может быть двух одинаковых.
- **Ключи неизменяемы** — числа, строки, кортежи.
- **Значения любые** — числа, строки, списки, словари.
- **Быстрый доступ** по ключу (O(1)).
- **Изменяемый** — можно добавлять и удалять.

**Аналогия:** телефонная книга, где имя — ключ, а номер — значение.

## 3. Создание словаря

### 3.1. Через фигурные скобки

```python
student = {
    "name": "Иван",
    "age": 20,
    "group": 214
}
```

### 3.2. Через `dict()`

```python
student = dict(name="Иван", age=20, group=214)
```

### 3.3. Из списка пар

```python
pairs = [("name", "Иван"), ("age", 20)]
student = dict(pairs)
```

### 3.4. Пустой словарь

```python
empty = {}
# или
empty = dict()
```

⚠️ **`{}` — это словарь**, а не множество. Для множества — `set()`.

---

## 4. Доступ по ключу

### 4.1. Через `[]`

```python
student = {"name": "Иван", "age": 20}

print(student["name"])   # Иван
print(student["age"])    # 20
```

⚠️ **Если ключа нет — ошибка `KeyError`:**

```python
print(student["email"])   # ❌ KeyError
```

### 4.2. Через `get()` — безопасно

```python
print(student.get("name"))           # Иван
print(student.get("email"))          # None
print(student.get("email", "нет"))   # "нет" — значение по умолчанию
```

⚠️ **`get()` — предпочтительный способ** для безопасного доступа.

### 4.3. Проверка наличия ключа

```python
if "name" in student:
    print("Есть ключ name")

if "email" not in student:
    print("Нет ключа email")
```

## 5. Изменение словаря

### 5.1. Добавление

```python
student = {"name": "Иван"}
student["age"] = 20           # добавляем
print(student)                # {'name': 'Иван', 'age': 20}
```

### 5.2. Изменение

```python
student["age"] = 21           # меняем
print(student["age"])         # 21
```

### 5.3. Удаление

| Способ | Что делает |
|--------|-----------|
| `del d[key]` | Удаляет ключ (ошибка, если нет) |
| `d.pop(key)` | Удаляет и возвращает значение |
| `d.pop(key, default)` | Удаляет или возвращает default |
| `d.clear()` | Очищает весь словарь |

```python
student = {"name": "Иван", "age": 20}

del student["age"]
print(student)                # {'name': 'Иван'}

age = student.pop("age", "нет")   # "нет" — ключа уже нет
print(age)
```

## 6. Методы словаря

### 6.1. `keys()` — все ключи

```python
student = {"name": "Иван", "age": 20, "group": 214}

keys = student.keys()
print(keys)             # dict_keys(['name', 'age', 'group'])

for key in student.keys():
    print(key)
```

### 6.2. `values()` — все значения

```python
values = student.values()
print(values)           # dict_values(['Иван', 20, 214])

for value in student.values():
    print(value)
```

### 6.3. `items()` — пары ключ-значение

```python
items = student.items()
print(items)
# dict_items([('name', 'Иван'), ('age', 20), ('group', 214)])

for key, value in student.items():
    print(f"{key}: {value}")
```

⚠️ **`items()` — самый удобный способ** для обхода словаря.

### 6.4. `get()` — безопасный доступ

```python
print(student.get("name"))           # Иван
print(student.get("email", "нет"))   # "нет"
```

### 6.5. `update()` — обновление

```python
student = {"name": "Иван"}
student.update({"age": 20, "group": 214})
print(student)
# {'name': 'Иван', 'age': 20, 'group': 214}
```

### 6.6. `setdefault()` — получить или создать

```python
student = {"name": "Иван"}
student.setdefault("age", 18)
print(student)   # {'name': 'Иван', 'age': 18}
```

### 6.7. Сводная таблица методов

| Метод | Что делает |
|-------|-----------|
| `keys()` | Все ключи |
| `values()` | Все значения |
| `items()` | Пары (ключ, значение) |
| `get(k, d)` | Значение или default |
| `update(d)` | Обновить словарь |
| `pop(k)` | Удалить и вернуть |
| `popitem()` | Удалить последнюю пару |
| `clear()` | Очистить |
| `copy()` | Копия |
| `setdefault(k, d)` | Получить или создать |

## 7. Обход словаря

### 7.1. По ключам

```python
student = {"name": "Иван", "age": 20}

for key in student:
    print(key)
```

⚠️ **Без `.keys()`** — по умолчанию итерируется по ключам.

### 7.2. По значениям

```python
for value in student.values():
    print(value)
```

### 7.3. По парам

```python
for key, value in student.items():
    print(f"{key}: {value}")
```

## 8. Вложенные словари

```python
students = {
    "Иван": {"age": 20, "group": 214},
    "Пётр": {"age": 22, "group": 215}
}

print(students["Иван"]["age"])   # 20
students["Иван"]["age"] = 21
```

### Обход вложенного словаря

```python
for name, info in students.items():
    print(f"{name}: {info['age']} лет, группа {info['group']}")
```

## 9. Словарь vs список

| Критерий | Список | Словарь |
|----------|:------:|:-------:|
| Доступ | По индексу (0, 1, 2...) | По ключу |
| Порядок | Упорядочен | Упорядочен (Python 3.7+) |
| Ключи | Нет | Есть |
| Дубликаты | Можно | Ключи — нет |
| Поиск | O(n) | O(1) |
| Когда использовать | Последовательность | Данные с именами |

## 10. Типовые задачи

### 10.1. Частотный анализ слов

```python
text = "кот пёс кот кот пёс"
words = text.split()
freq = {}

for word in words:
    freq[word] = freq.get(word, 0) + 1

print(freq)   # {'кот': 3, 'пёс': 2}
```

### 10.2. База данных студентов

```python
students = [
    {"name": "Иван", "grade": 4.5},
    {"name": "Пётр", "grade": 3.8},
    {"name": "Анна", "grade": 4.9}
]

for s in students:
    if s["grade"] > 4:
        print(s["name"])
```

### 10.3. Телефонная книга

```python
phonebook = {}

def add_contact(name, phone):
    phonebook[name] = phone

def find(name):
    return phonebook.get(name, "Не найден")

add_contact("Иван", "+7-900-123-45-67")
print(find("Иван"))   # +7-900-123-45-67
```

### 10.4. Инвентарь

```python
inventory = {"яблоки": 10, "бананы": 5}

inventory["яблоки"] += 3
inventory["груши"] = 7

for item, count in inventory.items():
    print(f"{item}: {count}")
```

### 10.5. Сортировка по значениям

```python
freq = {"кот": 3, "пёс": 2, "мышь": 1}

sorted_items = sorted(freq.items(), key=lambda x: x[1], reverse=True)

for word, count in sorted_items:
    print(f"{word}: {count}")
```

## 11. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| `d["нет_ключа"]` | `KeyError` | `d.get("нет_ключа")` |
| `d.keys()[0]` | `dict_keys` не индексируется | `list(d.keys())[0]` |
| Ключ — список | Список не хэшируется | Использовать кортеж |
| Изменение словаря в цикле | RuntimeError | Итерировать по копии |
| `{}` как множество | Это словарь | `set()` |
| Забыли `d[k] = ...` | Не добавится | Присвоить |

**Пример ошибки:**

```python
d = {"a": 1, "b": 2}
for key in d:
    if key == "a":
        del d[key]   # ❌ RuntimeError

# Правильно:
for key in list(d.keys()):
    if key == "a":
        del d[key]   # ✅
```

## 12. Итоги

- **Словарь** — коллекция пар «ключ → значение».
- **Ключи уникальны** и неизменяемы.
- **Доступ** через `[]` (ошибка) или `get()` (безопасно).
- **Методы:** `keys()`, `values()`, `items()`, `get()`, `update()`, `pop()`.
- **Обход** через `for key, value in d.items()`.
- **Поиск** O(1) — быстрее списка.
- **Частотный анализ** — типичная задача словарей.

# Практическое занятие 11. Частые сценарии: подсчёт количества, вычисление суммы и произведения

## Теория

При работе с циклами часто встречаются три типовые задачи: **подсчёт количества** элементов, удовлетворяющих условию, **вычисление суммы** и **вычисление произведения**. Эти сценарии повторяются почти в каждой программе — от простых учебных задач до серьёзных проектов.

### Подсчёт количества

Задача: узнать, сколько раз выполнилось условие, сколько элементов в последовательности, сколько чисел обладают нужным свойством.

**Шаблон:**
```python
count = 0
for элемент in последовательность:
    if условие:
        count += 1
print(count)
```

**Пример 1. Сколько чётных чисел от 1 до 100:**
```python
count = 0
for i in range(1, 101):
    if i % 2 == 0:
        count += 1
print(f"Чётных чисел: {count}")
```

**Пример 2. Сколько цифр в числе:**
```python
n = int(input("Введите число: "))
count = 0
while n > 0:
    count += 1
    n //= 10
print(f"Цифр: {count}")
```

**Пример 3. Сколько положительных чисел ввёл пользователь:**
```python
count = 0
while True:
    x = float(input("Число (0 — стоп): "))
    if x == 0:
        break
    if x > 0:
        count += 1
print(f"Положительных: {count}")
```

### Вычисление суммы

Задача: сложить все элементы, удовлетворяющие условию, или всю последовательность.

**Шаблон:**
```python
total = 0
for элемент in последовательность:
    total += элемент
print(total)
```

**Пример 1. Сумма чисел от 1 до N:**
```python
n = int(input("Введите N: "))
total = 0
for i in range(1, n + 1):
    total += i
print(f"Сумма: {total}")
```

**Пример 2. Сумма цифр числа:**
```python
n = int(input("Введите число: "))
total = 0
while n > 0:
    total += n % 10
    n //= 10
print(f"Сумма цифр: {total}")
```

**Пример 3. Сумма только чётных чисел:**
```python
total = 0
for i in range(1, 101):
    if i % 2 == 0:
        total += i
print(f"Сумма чётных: {total}")
```

### Вычисление произведения

Задача: перемножить все элементы или элементы, удовлетворяющие условию. Здесь важно правильно выбрать начальное значение — **1**, а не 0, иначе результат всегда будет нулём.

**Шаблон:**
```python
product = 1
for элемент in последовательность:
    product *= элемент
print(product)
```

**Пример 1. Факториал числа:**
```python
n = int(input("Введите N: "))
product = 1
for i in range(1, n + 1):
    product *= i
print(f"{n}! = {product}")
```

**Пример 2. Произведение цифр числа:**
```python
n = int(input("Введите число: "))
product = 1
while n > 0:
    product *= n % 10
    n //= 10
print(f"Произведение цифр: {product}")
```

**Пример 3. Произведение чисел, кратных 3:**
```python
product = 1
found = False
for i in range(1, 21):
    if i % 3 == 0:
        product *= i
        found = True
if found:
    print(f"Произведение: {product}")
else:
    print("Нет чисел, кратных 3")
```

### Разные способы решения одной задачи

Одну и ту же задачу можно решить по-разному. Разберём на примере подсчёта суммы чисел от 1 до N.

**Способ 1. Цикл for:**
```python
n = int(input("N: "))
total = 0
for i in range(1, n + 1):
    total += i
print(total)
```

**Способ 2. Цикл while:**
```python
n = int(input("N: "))
total = 0
i = 1
while i <= n:
    total += i
    i += 1
print(total)
```

**Способ 3. Формула (без цикла):**
```python
n = int(input("N: "))
total = n * (n + 1) // 2
print(total)
```

**Способ 4. Встроенная функция sum с range:**
```python
n = int(input("N: "))
total = sum(range(1, n + 1))
print(total)
```

Все четыре способа дадут одинаковый результат. В учебных задачах обычно требуют решить через цикл — чтобы отработать навык. Формула и `sum()` удобны на практике, но не показывают понимание цикла.

### Разные способы решения задачи «сумма цифр числа»

**Способ 1. Через while и деление:**
```python
n = int(input("Число: "))
total = 0
while n > 0:
    total += n % 10
    n //= 10
print(total)
```

**Способ 2. Через строку:**
```python
n = input("Число: ")
total = 0
for ch in n:
    total += int(ch)
print(total)
```

**Способ 3. Через генератор и sum:**
```python
n = input("Число: ")
total = sum(int(ch) for ch in n)
print(total)
```

Первый способ — классический алгоритмический. Второй — использует тот факт, что строка в Python — это последовательность символов. Третий — компактная запись второго.

### Комбинирование: счётчик + сумма + произведение

В одной задаче часто нужно посчитать всё сразу.

**Пример: анализ последовательности чисел.**
```python
count = 0
total = 0
product = 1

while True:
    x = int(input("Число (0 — стоп): "))
    if x == 0:
        break
    count += 1
    total += x
    product *= x

print(f"Количество: {count}")
print(f"Сумма: {total}")
print(f"Произведение: {product}")
```

### Особенности сценариев

**Начальное значение счётчика — 0.** Он увеличивается на 1 при каждом попадании.

**Начальное значение суммы — 0.** Это нейтральный элемент для сложения.

**Начальное значение произведения — 1.** Если поставить 0, всё обнулится. Это одна из самых частых ошибок новичков.

**Проверка на пустую последовательность.** Если чисел нет, сумма останется 0, а произведение — 1. Иногда это нужно обрабатывать отдельно, особенно для произведения: если ни одного числа не было, произведение должно быть неопределено, а не 1.

**Подсчёт можно заменить на `len()`**, если последовательность хранится в списке. Но при работе с потоком ввода или вычисляемыми значениями счётчик остаётся основным инструментом.

**Сумму можно заменить на `sum()`**, если все элементы уже есть в коллекции.

**Для произведения встроенной функции нет.** Приходится использовать цикл.

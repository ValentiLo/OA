## 2. Краткая теория

### 2.1. Синтаксис

```python
if условие:
    тело
elif другое_условие:
    тело
else:
    тело_по_умолчанию
```

### 2.2. Операторы сравнения

| Оператор | Что означает |
|:--------:|--------------|
| `==` | Равно |
| `!=` | Не равно |
| `>` | Больше |
| `<` | Меньше |
| `>=` | Больше или равно |
| `<=` | Меньше или равно |

### 2.3. Логические операторы

| Оператор | Что означает |
|:--------:|--------------|
| `and` | И |
| `or` | ИЛИ |
| `not` | НЕ |

### 2.4. Правила

- **Двоеточие** после условия обязательно.
- **Отступ** — 4 пробела.
- **`elif`** — «иначе если», проверяется до первого совпадения.
- **`else`** — «всё остальное», без условия.

### 🟢 Уровень 1. Базовые задачи

#### Задание 1. Чётное или нечётное

**Условие:** запросить число и определить, чётное оно или нечётное.

**Пример:**

```
Ввод: 7
Вывод: Нечётное
```

**Решение:**

```python
n = int(input("Введите число: "))
if n % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
```

#### Задание 2. Положительное, отрицательное или ноль

**Условие:** запросить число и определить его знак.

**Пример:**

```
Ввод: -5
Вывод: Отрицательное
```

**Решение:**

```python

if n > 0:

    print("Ноль")
```

#### Задание 8. Високосный год

**Условие:** запросить год. Определить, високосный ли он.

**Правило:**
- Год делится на 4 — високосный.
- Но если делится на 100 — не високосный.
- Но если делится на 400 — високосный.

**Решение:**

```python
year = int(input("Год: "))

if year % 400 == 0:
    print("Високосный")
elif year % 100 == 0:
    print("Не високосный")
elif year % 4 == 0:
    print("Високосный")
else:
    print("Не високосный")
```

#### Задание 9. Калькулятор

**Условие:** запросить два числа и операцию (`+`, `-`, `*`, `/`). Вывести результат.

**Пример:**

```
Ввод: 10 3 +
Вывод: 13
```

**Решение:**

```python
a = float(input("Первое число: "))
b = float(input("Второе число: "))
op = input("Операция: ")

if op == "+":
    print(a + b)
elif op == "-":
    print(a - b)
elif op == "*":
    print(a * b)
elif op == "/":
    if b != 0:
        print(a / b)
    else:
        print("Деление на ноль")
else:
    print("Неизвестная операция")
```

#### Задание 10. Скидка в магазине

**Условие:** запросить сумму покупки. Если ≥ 1000 — скидка 10%, если ≥ 5000 — 20%, если ≥ 10000 — 30%. Иначе — без скидки.

**Решение:**

```python
total = float(input("Сумма: "))

if total >= 10000:
    discount = 0.30
elif total >= 5000:
    discount = 0.20
elif total >= 1000:
    discount = 0.10
else:
    discount = 0

final = total * (1 - discount)
print(f"Итог: {final:.2f}")
```

#### Задание 13. Тип треугольника

**Условие:** запросить три стороны. Определить, существует ли треугольник (сумма двух сторон больше третьей). Если да — определить тип (равносторонний, равнобедренный, разносторонний).

**Решение:**

```python
a = float(input("Сторона a: "))
b = float(input("Сторона b: "))
c = float(input("Сторона c: "))

if a + b > c and a + c > b and b + c > a:
    if a == b == c:
        print("Равносторонний")
    elif a == b or a == c or b == c:
        print("Равнобедренный")
    else:
        print("Разносторонний")
else:
    print("Треугольник не существует")
```

#### Задание 18. Проверка даты

**Условие:** запросить день, месяц, год. Проверить, корректна ли дата.

**Решение:**

```python
day = int(input("День: "))
month = int(input("Месяц: "))
year = int(input("Год: "))

valid = False

if 1 <= month <= 12:
    if month in (1, 3, 5, 7, 8, 10, 12):
        max_day = 31
    elif month in (4, 6, 9, 11):
        max_day = 30
    else:  # февраль
        # високосный?
        if (year % 400 == 0) or (year % 4 == 0 and year % 100 != 0):
            max_day = 29
        else:
            max_day = 28

    if 1 <= day <= max_day:
        valid = True

if valid:
    print("Дата корректна")
else:
    print("Дата некорректна")
```

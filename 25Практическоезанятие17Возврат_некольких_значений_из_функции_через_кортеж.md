## 2. Краткая теория

### 2.1. Как функция возвращает несколько значений

В Python функция возвращает **один объект**. Если написать:

```python
def f():
    return 1, 2
```

— она вернёт **кортеж** `(1, 2)`.

**Способы получить результат:**

```python
# Распаковка
a, b = f()

# Как кортеж
result = f()
print(result[0], result[1])

# Игнорирование части
a, _ = f()
```

### 2.2. Что можно вернуть

| Что возвращается | Пример |
|------------------|--------|
| Кортеж | `return a, b` |
| Список | `return [a, b]` |
| Словарь | `return {"min": a, "max": b}` |
| `None` | `return` (без значения) |

### 2.3. Правила

- **`return` завершает функцию** — код после не выполняется.
- **Без `return`** функция возвращает `None`.
- **Возвращать можно любое количество значений.**
- **Распаковка** — самый удобный способ получить результат.

#### Задание 6. Квадратное уравнение

**Условие:** написать функцию, возвращающую корни квадратного уравнения `ax² + bx + c = 0` или `None`, если корней нет.

**Решение:**

```python
import math

def solve_quadratic(a, b, c):
    d = b**2 - 4*a*c
    if d < 0:
        return None
    if d == 0:
        return -b / (2*a),
    x1 = (-b + math.sqrt(d)) / (2*a)
    x2 = (-b - math.sqrt(d)) / (2*a)
    return x1, x2

result = solve_quadratic(1, -5, 6)
if result is None:
    print("Корней нет")
else:
    print(f"Корни: {result}")
```

**Вывод:**
```
Корни: (3.0, 2.0)
```

#### Задание 18. Работа с датой

**Условие:** функция принимает дату `(день, месяц, год)` и возвращает `(bool, str)` — корректна ли и её описание.

**Решение:**

```python
def check_date(day, month, year):
    if not (1 <= month <= 12):
        return False, "Неверный месяц"

    if month in (1, 3, 5, 7, 8, 10, 12):
        max_day = 31
    elif month in (4, 6, 9, 11):
        max_day = 30
    else:
        leap = (year % 400 == 0) or (year % 4 == 0 and year % 100 != 0)
        max_day = 29 if leap else 28

    if not (1 <= day <= max_day):
        return False, "Неверный день"

    return True, f"{day:02d}.{month:02d}.{year}"

ok, desc = check_date(29, 2, 2024)
print(f"Корректна: {ok}, Дата: {desc}")
```

**Вывод:**
```
Корректна: True, Дата: 29.02.2024
```

#### Задание 20. Полная статистика текста

**Условие:** функция возвращает словарь с полной статистикой текста:
- количество слов,
- количество символов,
- количество гласных,
- самое частое слово.

**Решение:**

```python
def full_stats(text):
    words = text.lower().split()
    vowels = "аеёиоуыэюяaeiou"

    # частоты
    freq = {}
    for w in words:
        freq[w] = freq.get(w, 0) + 1

    most_common = max(freq, key=freq.get) if freq else ""

    return {
        "words": len(words),
        "chars": len(text),
        "vowels": sum(1 for ch in text.lower() if ch in vowels),
        "most_common": most_common
    }

result = full_stats("Python это очень круто Python это")
for key, value in result.items():
    print(f"{key}: {value}")
```

**Вывод:**
```
words: 7
chars: 34
vowels: 11
most_common: python
```

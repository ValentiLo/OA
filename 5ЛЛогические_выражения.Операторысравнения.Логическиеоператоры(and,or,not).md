# Логические выражения. Операторы сравнения. Логические операторы. Условный оператор if

## 1. Логические выражения

Логическое выражение — это выражение, которое может быть либо истинным (`True`), либо ложным (`False`). Именно на таких выражениях строятся все условия в программировании.

```python
5 > 3          # True
10 == 10       # True
7 < 2          # False
"a" == "b"     # False
```

Результат логического выражения можно сохранить в переменную:

```python
is_adult = 20 >= 18
print(is_adult)          # True
print(type(is_adult))    # <class 'bool'>
```

Логические выражения используются везде, где нужно принять решение: в `if`, `while`, при фильтрации данных.

---

## 2. Операторы сравнения

Это операторы, которые сравнивают два значения и возвращают `True` или `False`.

| Оператор | Значение | Пример | Результат |
|----------|----------|--------|-----------|
| `==` | Равно | `5 == 5` | `True` |
| `!=` | Не равно | `5 != 3` | `True` |
| `>` | Больше | `7 > 4` | `True` |
| `<` | Меньше | `2 < 1` | `False` |
| `>=` | Больше или равно | `5 >= 5` | `True` |
| `<=` | Меньше или равно | `3 <= 2` | `False` |

### Важные моменты

**Не путайте `=` и `==`.** Одинарное равно — присваивание, двойное — сравнение.

```python
x = 5       # присвоили
x == 5      # сравнили
```

**Сравнение строк** идёт по алфавиту (по кодам символов):

```python
print("apple" < "banana")   # True
print("abc" == "abc")       # True
print("Apple" < "apple")    # True — заглавные буквы идут раньше
```

**Сравнение чисел с плавающей точкой** может быть неточным из-за особенностей хранения:

```python
print(0.1 + 0.2 == 0.3)     # False!
print(abs((0.1 + 0.2) - 0.3) < 1e-9)  # True
```

**Цепочки сравнений** в Python можно писать компактно:

```python
x = 5
print(1 < x < 10)           # True
print(0 <= x <= 5)          # True
```

Это эквивалентно `1 < x and x < 10`, но короче и читается лучше.

## 3. Логические операторы

Логические операторы объединяют несколько логических выражений в одно.

### and — логическое И

Возвращает `True`, только если **оба** операнда истинны.

| A | B | A and B |
|---|---|---------|
| True | True | True |
| True | False | False |
| False | True | False |
| False | False | False |

```python
age = 25
has_passport = True
print(age >= 18 and has_passport)   # True
```

### or — логическое ИЛИ

Возвращает `True`, если **хотя бы один** операнд истинен.

| A | B | A or B |
|---|---|--------|
| True | True | True |
| True | False | True |
| False | True | True |
| False | False | False |

```python
is_weekend = False
is_holiday = True
print(is_weekend or is_holiday)     # True
```

### not — логическое НЕ

Инвертирует значение: `True` → `False`, `False` → `True`.

```python
print(not True)          # False
print(not False)         # True
print(not(5 > 3))        # False
```

### Приоритет логических операторов

1. `not` — самый высокий
2. `and` — средний
3. `or` — самый низкий

```python
# Читается как: not(True) or (True and False) = False or False = False
print(not True or True and False)   # False
```

При сомнениях — ставьте скобки. Это улучшает читаемость:

```python
print((not True) or (True and False))   # False
```

### Особенности and и or

Операторы `and` и `or` возвращают не `True`/`False`, а **последнее проверенное значение**. Это иногда используется:

```python
name = input("Имя: ") or "Гость"
print(name)             # если пусто — "Гость"

result = 0 and 5
print(result)           # 0 — потому что 0 ложное, дальше не проверяем
```

Но в учебных задачах обычно работают с чистым `True`/`False`.

## 4. Условный оператор if

### Простая форма

```python
if условие:
    # блок выполнится, если условие истинно
```

```python
x = 10
if x > 5:
    print("x больше 5")
```

### if-else

```python
if условие:
    # если истина
else:
    # если ложь
```

```python
x = 3
if x > 5:
    print("Больше 5")
else:
    print("Не больше 5")
```

### if-elif-else

```python
if условие1:
    # блок 1
elif условие2:
    # блок 2
elif условие3:
    # блок 3
else:
    # если все ложны
```

Проверка идёт сверху вниз. Как только находится истинное условие — выполняется его блок, остальные пропускаются.

```python
score = 75
if score >= 90:
    print("Отлично")
elif score >= 75:
    print("Хорошо")
elif score >= 60:
    print("Удовлетворительно")
else:
    print("Неудовлетворительно")
```

Результат: `Хорошо`.

## 5. Вложенные условия

Один `if` может находиться внутри другого. Каждый уровень добавляет отступ.

```python
x = 15
if x > 0:
    print("Положительное")
    if x % 2 == 0:
        print("Чётное")
    else:
        print("Нечётное")
else:
    print("Не положительное")
```

Результат:
```
Положительное
Нечётное
```

Вложенность полезна, но не должна быть глубокой. 2–3 уровня — разумный предел. Если больше — лучше вынести логику в отдельную функцию.

## 6. Истинность значений

В Python почти любой объект можно проверить на истинность. **Ложными** считаются:

- `0`, `0.0`
- `""` (пустая строка)
- `[]`, `()`, `{}` (пустые коллекции)
- `None`
- `False`

Всё остальное — **истинно**.

```python
if "abc":
    print("Непустая строка — истина")

if 0:
    print("Это не выполнится")

if []:
    print("И это не выполнится")
```

Это позволяет писать компактные проверки:

```python
name = input("Введите имя: ")
if name:
    print(f"Привет, {name}")
else:
    print("Вы не ввели имя")
```

## 8. Типичные ошибки

**Забыли двоеточие:**
```python
if x > 5      # SyntaxError
    print("ok")
```

**Забыли отступ:**
```python
if x > 5:
print("ok")   # IndentationError
```

**Путают `=` и `==`:**
```python
if x = 5:     # SyntaxError
    print("ok")
```

**Неправильный порядок условий в elif:**
```python
score = 95
if score >= 60:
    print("Сдал")
elif score >= 90:   # сюда никогда не попадём
    print("Отлично")
```

Правильно:
```python
if score >= 90:
    print("Отлично")
elif score >= 60:
    print("Сдал")
```

**Логическая ошибка с and/or:**
```python
# Хотели: не (a и b), написали: (не a) и b
x = 5
if not x > 0 and x < 10:    # читается как (not x > 0) and (x < 10) = False
    print("ok")
```

Лучше использовать скобки:
```python
if not (x > 0 and x < 10):
    print("ok")
```

## 9. Итог

- **Логическое выражение** возвращает `True` или `False`.
- **Операторы сравнения:** `==`, `!=`, `>`, `<`, `>=`, `<=`. Работают с числами, строками, цепочками.
- **Логические операторы:** `and`, `or`, `not`. Приоритет: `not` → `and` → `or`.
- **`if`** выполняет блок, если условие истинно.
- **`if-else`** выбирает один из двух блоков.
- **`if-elif-else`** выбирает один из нескольких.
- **Вложенные условия** — допустимы, но не глубже 2–3 уровней.
- **Истинность:** `0`, `""`, `[]`, `None`, `False` — ложные, остальное — истинное.
- **Тернарный оператор** — компактная запись выбора.

Условные операторы — сердце любой программы. Умение строить правильные условия и не путаться в логике — ключевой навык, который оттачивается практикой.

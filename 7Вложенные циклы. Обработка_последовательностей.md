## 2. Что такое вложенный цикл

**Вложенный цикл** — это цикл **внутри** другого цикла.

```python
for i in range(3):
    for j in range(3):
        print(i, j)
```

**Как работает:**
1. Внешний цикл делает **одну** итерацию.
2. Внутренний цикл выполняет **все** свои итерации.
3. Внешний цикл делает **следующую** итерацию.
4. И так, пока внешний не завершится.

**Схема:**

```
Внешний i=0:
    Внутренний j=0
    Внутренний j=1
    Внутренний j=2
Внешний i=1:
    Внутренний j=0
    Внутренний j=1
    Внутренний j=2
Внешний i=2:
    Внутренний j=0
    Внутренний j=1
    Внутренний j=2
```

**Всего итераций:** 3 × 3 = **9**.

⚠️ **Общее число итераций = произведение количеств.** Если внешний `n`, внутренний `m`, то `n × m`.

## 3. Простой пример: таблица умножения

```python
for i in range(1, 10):
    for j in range(1, 10):
        print(f"{i*j:4}", end="")
    print()
```

**Вывод:**

```
   1   2   3   4   5   6   7   8   9
   2   4   6   8  10  12  14  16  18
   3   6   9  12  15  18  21  24  27
   ...
```

**Что происходит:**
- Внешний цикл — строки таблицы.
- Внутренний — столбцы.
- `end=""` — не переводить строку внутри.
- `print()` после внутреннего — перевод строки.

## 4. Обработка последовательностей

**Последовательность** — это набор элементов, по которым можно итерироваться:

- строки (`"abc"`),
- списки (`[1, 2, 3]`),
- кортежи (`(1, 2, 3)`),
- словари (`{"a": 1}`),
- диапазоны (`range(5)`),
- файлы.

### 4.1. Обход строки

```python
word = "Python"
for ch in word:
    print(ch)
```

**Вывод:** по одной букве на строке.

### 4.2. Обход списка

```python
fruits = ["яблоко", "банан", "вишня"]
for fruit in fruits:
    print(fruit)
```

### 4.3. Обход с индексом

```python
fruits = ["яблоко", "банан", "вишня"]
for i in range(len(fruits)):
    print(i, fruits[i])
```

**Или через `enumerate`:**

```python
for i, fruit in enumerate(fruits):
    print(i, fruit)
```

⚠️ **`enumerate` — предпочтительнее.** Короче и безопаснее.

### 4.4. Обход словаря

```python
student = {"name": "Иван", "age": 20, "group": 214}

for key in student:              # по ключам
    print(key)

for key in student.keys():       # явно по ключам
    print(key)

for value in student.values():   # по значениям
    print(value)

for key, value in student.items():   # по парам
    print(key, value)
```

### 4.5. Параллельный обход

```python
names = ["Иван", "Пётр", "Анна"]
ages = [20, 25, 22]

for name, age in zip(names, ages):
    print(f"{name} — {age}")
```

## 5. Обработка двумерных структур

**Двумерная структура** — список списков (матрица).

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

### 5.1. Обход матрицы

```python
for row in matrix:
    for element in row:
        print(element, end=" ")
    print()
```

**Вывод:**
```
1 2 3
4 5 6
7 8 9
```

### 5.2. Обход по индексам

```python
for i in range(len(matrix)):
    for j in range(len(matrix[i])):
        print(matrix[i][j], end=" ")
    print()
```

### 5.3. Сумма всех элементов

```python
total = 0
for row in matrix:
    for element in row:
        total += element
print(total)   # 45
```

### 5.4. Поиск элемента

```python
target = 5
for i, row in enumerate(matrix):
    for j, element in enumerate(row):
        if element == target:
            print(f"Найдено на позиции ({i}, {j})")
```

## 7. `break` и `continue` во вложенных циклах

### 7.1. `break` выходит только из **внутреннего** цикла

```python
for i in range(3):
    for j in range(3):
        if j == 1:
            break
        print(i, j)
```

**Вывод:**
```
0 0
1 0
2 0
```

**Внешний цикл продолжается.**

### 7.2. Выход из обоих циклов через флаг

```python
found = False
for i in range(3):
    for j in range(3):
        if i * j == 4:
            found = True
            break
    if found:
        break
```

### 7.3. Выход через функцию

```python
def find(matrix, target):
    for i, row in enumerate(matrix):
        for j, element in enumerate(row):
            if element == target:
                return i, j
    return None
```

⚠️ **`return` выходит сразу из функции — из обоих циклов.**

### 7.4. `continue`

```python
for i in range(3):
    for j in range(3):
        if j == 1:
            continue
        print(i, j)
```

**Вывод:**
```
0 0
0 2
1 0
1 2
2 0
2 2
```

`j == 1` пропускается, но внутренний цикл продолжается.

## 8. Генераторы для двумерных структур

**Генератор списков** — короткая запись циклов.

### 8.1. Обычный

```python
squares = [x**2 for x in range(10)]
```

### 8.2. С условием

```python
evens = [x for x in range(10) if x % 2 == 0]
```

### 8.3. Двумерный

```python
matrix = [[i*j for j in range(3)] for i in range(3)]
# [[0, 0, 0], [0, 1, 2], [0, 2, 4]]
```

### 8.4. Сплющивание

```python
matrix = [[1, 2], [3, 4], [5, 6]]
flat = [x for row in matrix for x in row]
# [1, 2, 3, 4, 5, 6]
```

⚠️ **Порядок циклов:** внешний **первым**, внутренний — вторым.

## 9. Практические примеры

### 9.1. Транспонирование матрицы

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]

transposed = []
for j in range(len(matrix[0])):
    row = []
    for i in range(len(matrix)):
        row.append(matrix[i][j])
    transposed.append(row)

print(transposed)   # [[1, 4], [2, 5], [3, 6]]
```

**Или через генератор:**

```python
transposed = [[row[i] for row in matrix] for i in range(len(matrix[0]))]
```

### 9.2. Подсчёт слов в строках

```python
lines = ["Привет мир", "Python это круто", "Я учусь"]
for i, line in enumerate(lines):
    words = line.split()
    print(f"Строка {i}: {len(words)} слов")
```

### 9.3. Таблица оценок

```python
students = {
    "Иван": [4, 5, 4],
    "Пётр": [3, 4, 5],
    "Анна": [5, 5, 5]
}

for name, grades in students.items():
    avg = sum(grades) / len(grades)
    print(f"{name}: средний балл {avg:.2f}")
```

## 10. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| Одинаковые имена переменных | `for i: for i:` — путаница | `i`, `j` или `row`, `col` |
| `break` во вложенном | Выходит только из внутреннего | Флаг / функция |
| Забыли `print()` после внутреннего | Всё в одну строку | Добавить `print()` |
| `range(len(matrix))` без `[i]` | Обращение ко всей строке | `matrix[i]` |
| Изменение коллекции в цикле | Непредсказуемо | Итерировать по копии |
| Дорогие операции внутри | Медленно | Оптимизировать |
| Глубокая вложенность (3+) | Сложно читать | Разбить на функции |

## 11. Сложность

| Вложенность | Сложность | Когда допустимо |
|:-----------:|:---------:|-----------------|
| 1 цикл | O(n) | Всегда |
| 2 цикла | O(n²) | Небольшие n |
| 3 цикла | O(n³) | Редко |
| 4+ | O(n⁴) | Почти никогда |

⚠️ **Для больших данных** вложенные циклы **медленны**. Используйте:

- генераторы,
- встроенные функции (`sum`, `max`, `min`),
- библиотеки (`numpy`).

---

## 12. Итоги

- **Вложенный цикл** — цикл внутри цикла.
- **Общее число итераций** = произведение.
- **Внешний цикл** — строки, **внутренний** — столбцы.
- **`break`** выходит только из **внутреннего**.
- **Флаг / функция** — для выхода из обоих.
- **`continue`** пропускает итерацию **внутреннего**.
- **Генераторы** — короткая запись для двумерных структур.
- **Сложность** O(n²) — для небольших данных.

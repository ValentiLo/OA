## 2. Краткая теория

### 2.1. `sort()` vs `sorted()`

| Метод | Что делает | Возвращает |
|-------|-----------|-----------|
| `lst.sort()` | Сортирует **на месте** | `None` |
| `sorted(lst)` | Создаёт **новый** список | Новый список |

```python
# sort() — меняет исходный список
nums = [3, 1, 2]
nums.sort()
print(nums)   # [1, 2, 3]

# sorted() — возвращает новый
nums = [3, 1, 2]
result = sorted(nums)
print(nums)     # [3, 1, 2] (не изменился)
print(result)   # [1, 2, 3]
```

### 2.2. Параметры

| Параметр | Что делает |
|----------|-----------|
| `key=` | Функция для вычисления ключа |
| `reverse=True` | Обратный порядок |

```python
nums = [3, 1, 2]
nums.sort(reverse=True)
print(nums)   # [3, 2, 1]
```

### 2.3. `key` — что это

**`key`** — функция, которая **преобразует** каждый элемент в значение для сравнения.

```python
words = ["banana", "apple", "cherry"]
words.sort(key=len)
print(words)   # ['apple', 'banana', 'cherry']
```

**Здесь `key=len`** — сравниваем не слова, а их длины.

#### Задание 7. По последней букве

**Условие:** отсортировать слова по последней букве.

**Решение:**

```python

words.sort(key=lambda w: w[-1])

```

⚠️ **`lambda`** — анонимная функция: берёт `w`, возвращает `w[-1]`.

#### Задание 14. Сортировка строк по количеству гласных

**Условие:** отсортировать слова по количеству гласных в них.

**Решение:**

```python
words = ["banana", "apple", "kiwi", "cherry"]
vowels = "aeiou"

def count_vowels(w):
    return sum(1 for ch in w.lower() if ch in vowels)

words.sort(key=count_vowels)
print(words)
```

#### Задание 18. Сортировка чисел по сумме цифр

**Условие:** отсортировать числа по сумме цифр.

**Решение:**

```python
nums = [123, 45, 6789, 12, 100]

def digit_sum(n):
    return sum(int(d) for d in str(n))

nums.sort(key=digit_sum)
print(nums)   # [100, 12, 123, 45, 6789]
```

**Проверка сумм:**
- `100` → 1
- `12` → 3
- `123` → 6
- `45` → 9
- `6789` → 30

#### Задание 19. Сортировка с `functools.cmp_to_key`

**Условие:** отсортировать числа так, чтобы чётные шли первыми, а внутри групп — по возрастанию.

**Решение:**

```python
from functools import cmp_to_key

def compare(a, b):
    if a % 2 == b % 2:
        return a - b
    return -1 if a % 2 == 0 else 1

nums = [5, 2, 8, 1, 9, 4]
nums.sort(key=cmp_to_key(compare))
print(nums)   # [2, 4, 8, 1, 5, 9]
```

⚠️ **`cmp_to_key`** — если нужна **сложная логика сравнения**.

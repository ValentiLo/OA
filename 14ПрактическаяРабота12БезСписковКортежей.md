## 1. Теория: Поиск максимума и минимума

### 1.1. Поиск максимума из двух чисел

Самый простой случай. Нужно сравнить два числа и выбрать большее.

**Способ 1: Через условный оператор `if-else`**
```python
a = int(input("Введите первое число: "))
b = int(input("Введите второе число: "))

if a > b:
    maximum = a
else:
    maximum = b

print("Максимум:", maximum)
```

**Способ 2: Через встроенную функцию `max()`**
```python
a = int(input("Введите первое число: "))
b = int(input("Введите второе число: "))

maximum = max(a, b)
print("Максимум:", maximum)
```

**Способ 3: Через тернарный оператор**
```python
a = int(input("Введите первое число: "))
b = int(input("Введите второе число: "))

maximum = a if a > b else b
print("Максимум:", maximum)
```

### 1.2. Поиск максимума из трёх чисел

Здесь уже нужно несколько сравнений.

**Способ 1: Вложенные условия**
```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))

if a > b:
    if a > c:
        maximum = a
    else:
        maximum = c
else:
    if b > c:
        maximum = b
    else:
        maximum = c

print("Максимум:", maximum)
```

**Способ 2: Последовательное сравнение (через `and`)**
```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))

if a >= b and a >= c:
    maximum = a
elif b >= a and b >= c:
    maximum = b
else:
    maximum = c

print("Максимум:", maximum)
```

**Способ 3: Через встроенную функцию `max()`**
```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))

maximum = max(a, b, c)
print("Максимум:", maximum)
```

### 1.3. Поиск максимума в последовательности (цикл)

Когда чисел много (например, пользователь вводит их до тех пор, пока не введёт 0), нужно использовать цикл.

**Способ 1: Через `while` с флагом (первое число — начальный максимум)**
```python
maximum = None  # Пока максимума нет
count = 0       # Счётчик введённых чисел

while True:
    x = int(input("Введите число (0 — стоп): "))
    if x == 0:
        break
    if count == 0 or x > maximum:
        maximum = x
    count += 1

if count > 0:
    print("Максимум:", maximum)
else:
    print("Числа не введены")
```

**Способ 2: Через `while` с начальным значением `-бесконечность`**
```python
maximum = float('-inf')  # Минус бесконечность
count = 0

while True:
    x = int(input("Введите число (0 — стоп): "))
    if x == 0:
        break
    if x > maximum:
        maximum = x
    count += 1

if count > 0:
    print("Максимум:", maximum)
else:
    print("Числа не введены")
```

## 2. Теория: Обмен значений переменных

### 2.1. Классический обмен (через временную переменную)

Самый понятный способ, работает во всех языках.

```python
a = 5
b = 10

temp = a
a = b
b = temp

print(a, b)  # 10 5
```

### 2.2. Обмен через арифметику (без третьей переменной)

Работает только для чисел.

```python
a = 5
b = 10

a = a + b  # a = 15
b = a - b  # b = 5
a = a - b  # a = 10

print(a, b)  # 10 5
```

### 2.3. Обмен через умножение и деление

Тоже только для чисел, но требует проверки, что числа не нулевые.

```python
a = 5
b = 10

a = a * b  # a = 50
b = a // b # b = 5
a = a // b # a = 10

print(a, b)  # 10 5
```

## 3. Пример решения одной задачи всеми способами

**Задача:** Пользователь вводит три числа. Найти максимум и минимум среди них, а затем обменять значения максимума и минимума.

### Способ 1: Классический (через `if-elif-else` и временную переменную)

```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))

# Поиск максимума и минимума
if a >= b and a >= c:
    maximum = a
elif b >= a and b >= c:
    maximum = b
else:
    maximum = c

if a <= b and a <= c:
    minimum = a
elif b <= a and b <= c:
    minimum = b
else:
    minimum = c

print(f"До обмена: max = {maximum}, min = {minimum}")

# Обмен значений (через временную переменную)
temp = maximum
maximum = minimum
minimum = temp

print(f"После обмена: max = {maximum}, min = {minimum}")
```

### Способ 2: Через встроенные функции `max()` и `min()`

```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))

maximum = max(a, b, c)
minimum = min(a, b, c)

print(f"До обмена: max = {maximum}, min = {minimum}")

# Обмен через арифметику
maximum = maximum + minimum
minimum = maximum - minimum
maximum = maximum - minimum

print(f"После обмена: max = {maximum}, min = {minimum}")
```

### Способ 3: Через поиск поочерёдно (без `max()` и `min()`)

```python
a = int(input("a = "))
b = int(input("b = "))
c = int(input("c = "))

# Начальные значения — первое число
maximum = a
minimum = a

# Сравниваем с b
if b > maximum:
    maximum = b
if b < minimum:
    minimum = b

# Сравниваем с c
if c > maximum:
    maximum = c
if c < minimum:
    minimum = c

print(f"До обмена: max = {maximum}, min = {minimum}")

# Обмен через временную переменную
temp = maximum
maximum = minimum
minimum = temp

print(f"После обмена: max = {maximum}, min = {minimum}")
```

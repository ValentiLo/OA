# Практическое занятие 11. Вложенные циклы: таблицы умножения, узоры из символов

## Теория

Вложенный цикл — это цикл, который находится внутри другого цикла. Внешний цикл отвечает за строки, внутренний — за столбцы или элементы внутри строки. Такая конструкция позволяет обрабатывать таблицы, матрицы, рисовать узоры и строить комбинации.

### Синтаксис

```python
for i in range(...):        # внешний цикл
    for j in range(...):    # внутренний цикл
        # тело внутреннего цикла
    # тело внешнего цикла (выполняется после внутреннего)
```

**Как это работает:**
1. Внешний цикл делает одну итерацию.
2. Для каждой итерации внешнего цикла внутренний цикл проходит полностью — от начала до конца.
3. Затем внешний цикл делает следующую итерацию, и внутренний снова запускается заново.

**Простой пример:**
```python
for i in range(3):
    for j in range(2):
        print(f"i={i}, j={j}")
```

Результат:
```
i=0, j=0
i=0, j=1
i=1, j=0
i=1, j=1
i=2, j=0
i=2, j=1
```

Внутренний цикл выполнился 3 × 2 = 6 раз.

### Отступы во вложенных циклах

Каждый уровень вложенности добавляет отступ:

```python
for i in range(3):          # 1-й уровень
    for j in range(3):      # 2-й уровень
        print(i, j)         # тело внутреннего цикла
    print("---")            # тело внешнего цикла, но не внутреннего
```

Результат:
```
0 0
0 1
0 2
---
1 0
1 1
1 2
---
2 0
2 1
2 2
---
```

`print("---")` выполняется один раз за итерацию внешнего цикла — после того как внутренний цикл завершится.

### Таблица умножения

Классический пример вложенных циклов — таблица умножения. Внешний цикл — первый множитель, внутренний — второй.

```python
for i in range(1, 6):
    for j in range(1, 6):
        print(f"{i*j:4}", end="")
    print()
```

Результат:
```
   1   2   3   4   5
   2   4   6   8  10
   3   6   9  12  15
   4   8  12  16  20
   5  10  15  20  25
```

Здесь `:4` означает «выровнять по правому краю в поле шириной 4 символа», а `end=""` запрещает переход на новую строку внутри строки таблицы.

### Узоры из символов

Вложенные циклы позволяют рисовать узоры. Внешний цикл — строки, внутренний — количество символов в строке.

**Прямоугольник:**
```python
for i in range(3):
    for j in range(5):
        print("*", end="")
    print()
```

Результат:
```
*****
*****
*****
```

**Треугольник:**
```python
for i in range(1, 6):
    for j in range(i):
        print("*", end="")
    print()
```

Результат:
```
*
**
***
****
*****
```

**Перевёрнутый треугольник:**
```python
for i in range(5, 0, -1):
    for j in range(i):
        print("*", end="")
    print()
```

Результат:
```
*****
****
***
**
*
```

**Пирамида:**
```python
n = 5
for i in range(1, n + 1):
    for j in range(n - i):
        print(" ", end="")
    for j in range(2 * i - 1):
        print("*", end="")
    print()
```

Результат:
```
    *
   ***
  *****
 *******
*********
```

### Вложенные циклы и таблицы

Вложенные циклы удобны для вывода таблиц с заголовками и рамками.

```python
print("+-------+-------+")
for i in range(1, 4):
    print(f"|   {i}   |  {i*10}  |")
    print("+-------+-------+")
```

Результат:
```
+-------+-------+
|   1   |  10   |
+-------+-------+
|   2   |  20   |
+-------+-------+
|   3   |  30   |
+-------+-------+
```

### Важные моменты

**Переменные циклов не должны совпадать.** Используйте `i` для внешнего и `j` для внутреннего. Если оба будут `i`, внешний счётчик будет перезаписан, и логика сломается.

**Количество итераций перемножается.** Если внешний цикл делает 5 итераций, а внутренний — 10, тело внутреннего выполнится 50 раз.

**Внутренний цикл полностью выполняется на каждой итерации внешнего.** Это не «продолжение», а новый запуск с начала.

**Не забывайте `print()` после внутреннего цикла.** Без него весь вывод окажется в одной строке.

**Вложенность не должна быть глубокой.** 2–3 уровня — предел читаемости. Больше — сигнал, что задачу нужно разбить на функции.

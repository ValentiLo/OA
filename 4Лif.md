## 2. Что такое условный оператор

**Условный оператор** позволяет программе **выбирать**, что делать, в зависимости от условий.

**Зачем нужно:**
- Реагировать на данные пользователя.
- Обрабатывать разные случаи.
- Проверять корректность данных.
- Реализовать логику «если — то — иначе».

**Аналогия:**
> «Если на улице дождь — возьми зонт. Иначе — надень очки.»

## 3. Оператор `if`

### 3.1. Синтаксис

```python
if условие:
    тело
```

**Как работает:**
1. Проверяется условие.
2. Если `True` — выполняется тело.
3. Если `False` — тело пропускается.

⚠️ **Двоеточие `:` обязательно** после условия.

⚠️ **Отступ обязателен** — 4 пробела.

### 3.2. Пример

```python
age = 20

if age >= 18:
    print("Совершеннолетний")
```

**Вывод:** `Совершеннолетний`

### 3.3. Что может быть условием

Любое **логическое выражение** или значение:

```python
if x > 5:           # сравнение
if x == 10:         # равенство
if x != 0:          # неравенство
if name:            # непустая строка
if items:           # непустой список
if flag:            # флаг
if x > 0 and x < 10:   # составное условие
if x in [1, 2, 3]:     # проверка вхождения
```

## 4. Оператор `if-else`

### 4.1. Синтаксис

```python
if условие:
    тело_если_истина
else:
    тело_если_ложь
```

**Как работает:**
- Если условие `True` — первое тело.
- Если `False` — второе.

⚠️ **`else` не имеет условия** — это «всё остальное».

### 4.2. Пример

```python
age = 15

if age >= 18:
    print("Совершеннолетний")
else:
    print("Несовершеннолетний")
```

**Вывод:** `Несовершеннолетний`

### 4.3. Проверка чётности

```python
n = 7

if n % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
```

**Вывод:** `Нечётное`

## 5. Оператор `if-elif-else`

### 5.1. Синтаксис

```python
if условие_1:
    тело_1
elif условие_2:
    тело_2
elif условие_3:
    тело_3
else:
    тело_по_умолчанию
```

**Как работает:**
1. Проверяется `условие_1`. Если `True` — тело_1, **остальные проверки пропускаются**.
2. Иначе проверяется `условие_2`. Если `True` — тело_2.
3. И так далее.
4. Если **ни одно** не сработало — `else`.

⚠️ **`elif` = `else if`** — «иначе если».

⚠️ **`else` опционален.**

### 5.2. Пример

```python
score = 75

if score >= 90:
    print("Отлично")
elif score >= 75:
    print("Хорошо")
elif score >= 60:
    print("Удовлетворительно")
else:
    print("Неудовлетворительно")
```

**Вывод:** `Хорошо`

**Что произошло:**
- `90` — нет.
- `75` — да → печатаем и **выходим**.
- Проверки `60` и `else` **не выполняются**.

### 5.3. Времена года

```python
month = 5

if month in (12, 1, 2):
    season = "Зима"
elif month in (3, 4, 5):
    season = "Весна"
elif month in (6, 7, 8):
    season = "Лето"
else:
    season = "Осень"

print(season)   # Весна
```

## 6. Несколько `if` vs `elif`

⚠️ **Это разные вещи!**

### Несколько `if` — проверяются **все**

```python
x = 10

if x > 5:
    print("Больше 5")
if x > 8:
    print("Больше 8")
if x > 15:
    print("Больше 15")
```

**Вывод:**
```
Больше 5
Больше 8
```

**Все подходящие условия выполняются.**

### `elif` — проверяется **до первого совпадения**

```python
x = 10

if x > 5:
    print("Больше 5")
elif x > 8:
    print("Больше 8")
elif x > 15:
    print("Больше 15")
```

**Вывод:**
```
Больше 5
```

**Только первое сработавшее.**

| Ситуация | Что использовать |
|----------|------------------|
| Взаимоисключающие варианты | `if-elif-else` |
| Независимые проверки | Несколько `if` |

## 7. Вложенные условия

**Вложенное условие** — `if` **внутри** `if`.

### 7.1. Синтаксис

```python
if условие_1:
    if условие_2:
        тело_1_2
    else:
        тело_1_не_2
else:
    тело_не_1
```

⚠️ **Каждое вложенное условие — свой отступ.**

### 7.2. Пример

```python
age = 25
has_passport = True

if age >= 18:
    if has_passport:
        print("Можно войти")
    else:
        print("Нужен паспорт")
else:
    print("Слишком молод")
```

**Вывод:** `Можно войти`

### 7.3. Объединение условий

Вложенные условия **можно объединить** через `and`:

```python
if age >= 18 and has_passport:
    print("Можно войти")
else:
    print("Нельзя войти")
```

⚠️ **Объединение короче**, но вложенность **нагляднее**, когда разные реакции на каждое условие.

### 7.4. Пример с разной реакцией

```python
if age >= 18:
    if has_passport:
        print("Вход разрешён")
    else:
        print("Нужен паспорт")
else:
    print("Слишком молод")
```

**Здесь три разных сообщения** — объединить через `and` **нельзя** без потери логики.

## 8. Тернарный оператор

**Сокращённая запись** `if-else` в одну строку.

```python
# Обычная запись
if x > 0:
    result = "положительное"
else:
    result = "не положительное"

# Тернарный оператор
result = "положительное" if x > 0 else "не положительное"
```

**Синтаксис:**

```python
значение_если_истина if условие else значение_если_ложь
```

⚠️ **Используйте для простых случаев.** Для сложной логики — обычный `if`.

## 9. Полезные приёмы

### 9.1. Проверка диапазона

```python
x = 5

if 0 < x < 10:
    print("В диапазоне")
```

### 9.2. Проверка на `None`

```python
if value is None:
    print("Нет значения")
```

### 9.3. Проверка на пустоту

```python
if not items:
    print("Список пуст")
```

### 9.4. Множественный выбор через `in`

```python
if command in ("exit", "quit", "q"):
    print("Выход")
```

### 9.5. Использование словаря вместо `elif`

Вместо длинной цепочки:

```python
if op == "+":
    result = a + b
elif op == "-":
    result = a - b
elif op == "*":
    result = a * b
elif op == "/":
    result = a / b
```

Можно так:

```python
operations = {
    "+": lambda a, b: a + b,
    "-": lambda a, b: a - b,
    "*": lambda a, b: a * b,
    "/": lambda a, b: a / b
}

result = operations[op](a, b)
```

⚠️ **Для больших списков вариантов** — словарь читаемее.

b = 3

## 11. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| `if x = 5:` | Присваивание вместо сравнения | `if x == 5:` |
| Забыли `:` | Синтаксис | `if условие:` |
| Нет отступа | Синтаксис | 4 пробела |
| `elif` после `else` | Порядок | `elif` перед `else` |
| Лишние `if` вместо `elif` | Все проверки сработают | `if-elif` |
| Вложенные `if` там, где нужен `and` | Сложно читать | Объединить |
| `if x == 5 or 10:` | `10` — всегда True | `if x == 5 or x == 10:` |

## 12. Итоги

- **`if`** — если условие истинно.
- **`else`** — иначе.
- **`elif`** — иначе если.
- **Несколько `if`** — все проверки.
- **`elif`** — до первого совпадения.
- **Вложенные условия** — `if` внутри `if`.
- **Тернарный оператор** — короткая запись.
- **`in`** — для проверки вхождения.

## 2. Краткая теория

### 2.1. Синтаксис

```python
while условие:
    тело цикла
```

### 2.2. Как работает

1. Проверяется условие.
2. Если `True` — выполняется тело.
3. Снова проверяется условие.
4. Если `False` — выход.

⚠️ **Условие проверяется ПЕРЕД каждой итерацией.**

### 2.3. Обязательно менять переменную

```python
i = 1
while i <= 5:
    print(i)
    i += 1        # ← обязательно, иначе бесконечный цикл
```

### 2.4. Бесконечный цикл с выходом

```python
while True:
    cmd = input("Команда: ")
    if cmd == "quit":
        break
    print(cmd)
```

### 2.5. Когда использовать `while`

- Число повторений **неизвестно**.
- Ожидание события (ввод, сигнал).
- Чтение до конца.
- Игра «угадай число».

### 🟢 Уровень 1. Базовые задачи

#### Задание 1. Сумма до нуля

**Условие:** запрашивать числа, пока не введён `0`. Найти сумму.

**Пример:**

```
Ввод: 5 3 2 0
Вывод: Сумма: 10
```

**Решение:**

```python
total = 0
while True:
    n = int(input("Число (0 для выхода): "))
    if n == 0:
        break
    total += n

print(f"Сумма: {total}")
```

#### Задание 4. Максимум и минимум

**Условие:** запрашивать числа до `0`. Найти максимум и минимум.

**Решение:**

```python
first = True
max_n = min_n = 0

while True:
    n = int(input("Число: "))
    if n == 0:
        break

    if first:
        max_n = min_n = n
        first = False
    else:
        if n > max_n:
            max_n = n
        if n < min_n:
            min_n = n

print(f"Максимум: {max_n}, Минимум: {min_n}")
```

**Пример:**


#### Задание 7. Сумма цифр числа

**Условие:** запросить число. Найти сумму его цифр.

**Пример:**

```
Ввод: 12345
Вывод: 15
```

**Решение:**

```python
n = int(input("Число: "))
total = 0

while n > 0:
    total += n % 10
    n //= 10

print(f"Сумма цифр: {total}")
```

---

#### Задание 8. Обратное число

**Условие:** запросить число. Вывести его в обратном порядке.

**Пример:**

```
Ввод: 12345
Вывод: 54321
```

**Решение:**

```python
n = int(input("Число: "))
reversed_n = 0

while n > 0:
    reversed_n = reversed_n * 10 + n % 10
    n //= 10

print(f"Обратное: {reversed_n}")
```

#### Задание 14. Выход по команде

**Условие:** запрашивать команды. Выход — при `"quit"`, `"exit"` или `"q"`. Иначе — «Неизвестная команда».

**Решение:**

```python
while True:
    cmd = input("Команда: ").lower()

    if cmd in ("quit", "exit", "q"):
        print("Выход")
        break

    print(f"Неизвестная команда: {cmd}")
```

### 🔴 Уровень 4. Повышенной сложности

#### Задание 15. Угадай число

**Условие:** компьютер загадывает число от 1 до 100. Пользователь угадывает. Компьютер подсказывает «больше»/«меньше». Посчитать попытки.

**Решение:**

```python
import random

secret = random.randint(1, 100)
attempts = 0

print("Угадайте число от 1 до 100")

while True:
    guess = int(input("Ваш вариант: "))
    attempts += 1

    if guess == secret:
        print(f"Угадали! Попыток: {attempts}")
        break
    elif guess < secret:
        print("Больше")
    else:
        print("Меньше")
```

#### Задание 16. Банкомат

**Условие:** реализовать мини-банкомат:

- `1` — баланс
- `2` — снять
- `3` — пополнить
- `0` — выход

**Решение:**

```python
balance = 1000

while True:
    print("\n1. Баланс")
    print("2. Снять")
    print("3. Пополнить")
    print("0. Выход")

    choice = input("Выбор: ")

    if choice == "0":
        print("До свидания")
        break
    elif choice == "1":
        print(f"Баланс: {balance}")
    elif choice == "2":
        amount = int(input("Сумма: "))
        if amount <= balance:
            balance -= amount
            print(f"Снято. Баланс: {balance}")
        else:
            print("Недостаточно средств")
    elif choice == "3":
        amount = int(input("Сумма: "))
        balance += amount
        print(f"Пополнено. Баланс: {balance}")
    else:
        print("Неверный выбор")
```

#### Задание 17. НОД двух чисел (алгоритм Евклида)

**Условие:** найти НОД двух чисел через `while`.

**Решение:**

```python
a = int(input("a: "))
b = int(input("b: "))

while b != 0:
    a, b = b, a % b

print(f"НОД: {a}")
```

#### Задание 19. Простые числа до N

**Условие:** вывести все простые числа до `N`.

**Решение:**

```python
n = int(input("N: "))

i = 2
while i <= n:
    is_prime = True
    j = 2
    while j * j <= i:
        if i % j == 0:
            is_prime = False
            break
        j += 1

    if is_prime:
        print(i, end=" ")
    i += 1
print()
```

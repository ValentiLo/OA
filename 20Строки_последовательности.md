## 2. Что такое строка

**Строка (`str`)** — это **неизменяемая последовательность символов** в Unicode.

**Ключевые свойства:**
- **Упорядоченная** — символы имеют индексы.
- **Неизменяемая** — нельзя изменить символ по индексу.
- **Итерируемая** — можно перебирать в цикле.
- **Индексируемая** — доступ по номеру.
- **Срезы** — можно брать подстроки.

**Создание строки:**

```python
s1 = "Привет"
s2 = 'Мир'
s3 = """Многострочная
строка"""
s4 = str(123)   # "123"
```

## 3. Строка как последовательность

### 3.1. Индексация

Каждый символ имеет индекс — **с нуля**.

```
П  р  и  в  е  т
0  1  2  3  4  5
-6 -5 -4 -3 -2 -1
```

```python
s = "Привет"

print(s[0])    # П
print(s[1])    # р
print(s[-1])   # т (последний)
print(s[-2])   # е
```

⚠️ **Отрицательные индексы** — с конца.

⚠️ **Выход за границы → `IndexError`.**

### 3.2. Срезы

**Срез** — подстрока от `start` до `end` (не включая `end`).

**Синтаксис:** `s[start:end:step]`

```python
s = "Python"

print(s[0:3])     # Pyt
print(s[:3])      # Pyt (с начала)
print(s[3:])      # hon (до конца)
print(s[:])       # Python (вся строка)
print(s[::2])     # Pto (каждый второй)
print(s[::-1])    # nohtyP (обратный порядок)
print(s[-3:])     # hon (последние 3)
```

⚠️ **Правая граница НЕ включается.**

### 3.3. Перебор символов

```python
s = "Python"

for ch in s:
    print(ch)
```

**С индексом:**

```python
for i, ch in enumerate(s):
    print(i, ch)
```

## 4. Неизменяемость строк

⚠️ **Строку нельзя изменить по индексу:**

```python
s = "Python"
s[0] = "J"    # ❌ TypeError
```

**Как изменить:**

```python
s = "Python"
s = "J" + s[1:]    # ✅ создаём новую строку
print(s)           # Jython
```

**Или через список:**

```python
lst = list("Python")
lst[0] = "J"
s = "".join(lst)
print(s)   # Jython
```

## 5. Основные методы строк

### 5.1. Изменение регистра

| Метод | Что делает |
|-------|-----------|
| `upper()` | В верхний регистр |
| `lower()` | В нижний регистр |
| `capitalize()` | Первая заглавная, остальные строчные |
| `title()` | Каждое слово с заглавной |
| `swapcase()` | Инвертировать регистр |

```python
s = "привет мир"

print(s.upper())        # ПРИВЕТ МИР
print(s.lower())        # привет мир
print(s.capitalize())   # Привет мир
print(s.title())        # Привет Мир
print(s.swapcase())     # ПРИВЕТ МИР
```

### 5.2. Поиск и замена

| Метод | Что делает |
|-------|-----------|
| `find(sub)` | Позиция первого вхождения (-1, если нет) |
| `rfind(sub)` | Позиция последнего вхождения |
| `index(sub)` | Как `find`, но `ValueError` |
| `count(sub)` | Сколько раз встречается |
| `replace(old, new)` | Заменить |
| `startswith(prefix)` | Начинается с |
| `endswith(suffix)` | Заканчивается на |
| `in` | Проверка вхождения |

```python
s = "Python — лучший язык"

print(s.find("лучший"))         # 9
print(s.find("Java"))           # -1
print(s.count("о"))             # 1
print(s.replace("лучший", "отличный"))
print(s.startswith("Python"))   # True
print(s.endswith("язык"))       # True
print("лучший" in s)            # True
```

### 5.3. Разбиение и объединение

| Метод | Что делает |
|-------|-----------|
| `split(sep)` | Разбить по разделителю |
| `rsplit(sep)` | Разбить справа |
| `splitlines()` | Разбить по строкам |
| `join(iterable)` | Объединить |
| `partition(sep)` | Разбить на 3 части |

```python
s = "яблоко,банан,вишня"

print(s.split(","))         # ['яблоко', 'банан', 'вишня']
print(s.split(",", 1))      # ['яблоко', 'банан,вишня']

words = ["Python", "это", "круто"]
print(" ".join(words))      # Python это круто

text = "Первая\nВторая\nТретья"
print(text.splitlines())    # ['Первая', 'Вторая', 'Третья']
```

### 5.4. Удаление пробелов

| Метод | Что делает |
|-------|-----------|
| `strip()` | Убрать пробелы с двух сторон |
| `lstrip()` | Слева |
| `rstrip()` | Справа |

```python
s = "   Python   "

print(s.strip())    # "Python"
print(s.lstrip())   # "Python   "
print(s.rstrip())   # "   Python"
```

⚠️ **`strip()` без аргументов** убирает пробелы, табы, переводы строк.

**С аргументом** — указанные символы:

```python
s = "***Python***"
print(s.strip("*"))   # Python
```

### 5.5. Проверки

| Метод | Что проверяет |
|-------|--------------|
| `isdigit()` | Только цифры |
| `isalpha()` | Только буквы |
| `isalnum()` | Буквы и цифры |
| `isspace()` | Только пробелы |
| `isupper()` | Все заглавные |
| `islower()` | Все строчные |
| `istitle()` | Слова с заглавной |

```python
print("123".isdigit())      # True
print("abc".isalpha())      # True
print("abc123".isalnum())   # True
print("   ".isspace())      # True
print("ABC".isupper())      # True
print("abc".islower())      # True
```

### 5.6. Выравнивание

| Метод | Что делает |
|-------|-----------|
| `center(width)` | По центру |
| `ljust(width)` | По левому краю |
| `rjust(width)` | По правому краю |
| `zfill(width)` | Дополнить нулями |

```python
s = "Python"

print(s.center(20, "-"))   # -------Python-------
print(s.ljust(20, "."))    # Python..............
print(s.rjust(20, "."))    # ..............Python
print("42".zfill(5))       # 00042
```

## 6. Форматирование строк

### 6.1. f-строки (современный способ)

```python
name = "Иван"
age = 20

print(f"{name} — {age} лет")     # Иван — 20 лет
print(f"{3.14159:.2f}")          # 3.14
print(f"{42:>10}")               # "        42"
print(f"{42:<10}")               # "42        "
print(f"{42:^10}")               # "    42    "
print(f"{42:05}")                # 00042
print(f"{255:x}")                # ff (hex)
print(f"{255:b}")                # 11111111 (bin)
```

### 6.2. `format()`

```python
print("{} — {} лет".format("Иван", 20))
print("{name} — {age}".format(name="Иван", age=20))
```

### 6.3. Через `%` (устаревший)

```python
print("%s — %d лет" % ("Иван", 20))
```

⚠️ **Рекомендуется f-строка** — короче и читаемее.

## 7. Конкатенация и повторение

```python
s1 = "Hello"
s2 = "World"

print(s1 + " " + s2)    # Hello World
print(s1 * 3)           # HelloHelloHello

# Через join (быстрее для многих строк)
words = ["a", "b", "c"]
print("".join(words))   # abc
```

⚠️ **`+` в цикле — медленно.** Используйте `join()`:

```python
# Плохо
result = ""
for w in words:
    result += w      # ❌ медленно

# Хорошо
result = "".join(words)   # ✅ быстро
```

## 8. Сравнение строк

Строки сравниваются **лексикографически** по ASCII-кодам.

```python
print("apple" == "apple")     # True
print("apple" < "banana")     # True
print("Apple" < "apple")      # True (A < a)
print("abc" < "abcd")         # True (короче — меньше)
```

⚠️ **Регистр важен.** `"Apple"` ≠ `"apple"`.

**Приведение к одному регистру:**

```python
s1 = "Hello"
s2 = "hello"

print(s1.lower() == s2.lower())   # True
```

## 9. Полезные приёмы

### 9.1. Разворот строки

```python
s = "Python"
print(s[::-1])   # nohtyP
```

### 9.2. Палиндром

```python
def is_palindrome(s):
    s = s.lower().replace(" ", "")
    return s == s[::-1]

print(is_palindrome("А роза упала на лапу Азора"))   # True
```

### 9.3. Подсчёт гласных

```python
s = "Привет мир"
vowels = "аеёиоуыэюя"
count = sum(1 for ch in s.lower() if ch in vowels)
print(count)   # 3
```

### 9.4. Удаление дубликатов

```python
s = "aaabbbccc"
result = "".join(dict.fromkeys(s))
print(result)   # abc
```

### 9.5. Разделение на слова

```python
s = "Python это круто"
words = s.split()
print(words)   # ['Python', 'это', 'круто']
```

### 9.6. Заглавные буквы

```python
s = "python это круто"
print(s.title())   # Python Это Круто
```

## 10. Типичные ошибки

| Ошибка | Что не так | Решение |
|--------|-----------|---------|
| `s[0] = "x"` | Строки неизменяемы | Создать новую строку |
| `s[100]` | IndexError | Проверять длину |
| `s + 5` | Разные типы | `s + str(5)` |
| `+=` в цикле | Медленно | `join()` |
| `s.find()` возвращает -1 | Не ошибка | Проверять `< 0` |
| `s.strip()` без аргумента | Убирает пробелы, не символы | Указать аргумент |
| Забыли `.lower()` при сравнении | Регистр важен | Приводить |
